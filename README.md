# 協力型ボードゲーム脅威トリアージアシスタント

パンデミック・アーカムホラー等の協力型ボードゲームで盤面上の脅威を管理するツールです。各脅威の緊急度・影響範囲・期限を入力するとスコア計算で優先順位を自動算出し、連鎖反応リスクのある脅威をバッジで可視化します。残りターン数と行動ポイントから今ターンの推奨対処手順を提示します。

## 機能
- ゲームプリセット選択（パンデミック / アーカムホラー / 汎用）
- 脅威の追加（名前・緊急度1-5・影響範囲・期限ターン・場所）
- 緊急度×影響範囲×時間プレッシャーのスコアによるトリアージ並び替え
- 同一場所の複数脅威を「連鎖リスク」バッジで可視化
- 🔴高/🟡中/🟢低 の色分けカード表示
- ターンカウントダウン管理（残りターン数の増減）
- 手札枚数・行動ポイントからの推奨対処手順提案
- 全消去・新ゲームボタン
